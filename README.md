AlphaBeta 🎮📚

AlphaBeta é um jogo educacional desenvolvido em Python com Pygame que aborda um problema social real: o analfabetismo funcional no Brasil.
Mais do que ensinar palavras, o jogo mostra como a alfabetização transforma vidas.

O jogador ajuda personagens inspirados em situações reais — uma idosa perdida nas ruas, um senhor tentando ler a bula de um remédio e uma mulher votando sozinha pela primeira vez — formando palavras corretamente através da combinação de sílabas.

Cada palavra concluída ilumina parte do cenário, simbolizando como a leitura traz autonomia, dignidade e inclusão social.

🌎 Problema Social Abordado

Segundo dados nacionais, milhões de brasileiros adultos ainda enfrentam dificuldades de leitura e escrita.
O jogo busca conscientizar sobre como algo simples para muitos — ler uma placa, entender uma receita médica ou votar sozinho — pode representar uma enorme conquista para outras pessoas.

No AlphaBeta, o analfabetismo não aparece como estatística, mas como histórias humanas.

✨ Objetivo do Jogo

O objetivo do jogador é:

Selecionar sílabas corretas
Formar palavras
Ajudar personagens a superar desafios do cotidiano
Iluminar o cenário ao completar cada fase

Cada acerto gera feedback visual imediato, reforçando a ideia de que o conhecimento transforma o mundo ao redor.

🕹️ Mecânicas Principais

✅ Formação de palavras por sílabas
✅ Sistema de fases com personagens diferentes
✅ Feedback visual e sonoro
✅ Cenário dinâmico que se ilumina conforme o progresso
✅ Narrativa integrada à jogabilidade
✅ Interface simples e acessível

🎨 Conceito Visual

O jogo começa em um ambiente escuro e silencioso.

Conforme o jogador forma palavras corretamente:

luzes acendem,
elementos aparecem,
personagens sorriem,
a cidade ganha vida.

A iluminação representa simbolicamente o impacto da alfabetização na sociedade.
