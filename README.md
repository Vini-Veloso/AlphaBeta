# AlphaBeta
AlphaBeta é um jogo de alfabetização em que o jogador ajuda personagens reais — uma idosa que se perde nas ruas, um senhor que não consegue ler a bula do remédio, uma mulher que nunca votou sozinha — a conquistarem sua primeira palavra.
A mecânica é simples: montar sílabas para formar palavras corretas. Mas o efeito é visual e imediato — cada acerto ilumina literalmente o cenário, que começa quase completamente escuro. Sem o jogador, o mundo fica no escuro. Com ele, a comunidade inteira se ilumina.
O jogo aborda os 29 milhões de brasileiros adultos analfabetos não como estatística, mas como histórias — mostrando que ler uma bula, encontrar uma rua ou votar sozinho são conquistas que a maioria de nós nunca percebeu que tinha.
